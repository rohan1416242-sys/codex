# Prebuilt binaries

Download these so you don't have to install Rust + build from source.

## Windows (your case)

1. Download `codex-nim-proxy.exe` and `run-codex-nim-proxy.ps1`
2. Put them in a folder like `C:\Tools\codex-proxy\`
3. Follow the setup steps in `INSTALL-WINDOWS.md` (also in this folder if present, or in the repo root docs)

## Linux / macOS

1. Download `codex-nim-proxy` and `run-codex-nim-proxy.sh`
2. `chmod +x codex-nim-proxy run-codex-nim-proxy.sh`
3. Run `./run-codex-nim-proxy.sh`
